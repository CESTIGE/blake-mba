課程單元

從問題出發，比從功能出發更接近市場

每個單元都對應一個風險。先驗證最大的不確定性，再決定是否投入下一步。

MODULE 01

選擇值得研究的問題

從生活、工作與產業觀察建立問題清單，評估急迫性與頻率。

產出：問題機會清單
MODULE 02

定義客群與假設

將「所有人都需要」縮小為一個可接觸、可訪談的早期客群。

產出：驗證假設地圖
MODULE 03

進行問題訪談

用非誘導式問題理解真實行為、替代方案與付出成本。

產出：訪談腳本與紀錄
MODULE 04

建立價值主張

用證據整理問題、承諾、差異與最小可行的解決方式。

產出：價值主張一頁紙
MODULE 05

用 AI 製作 MVP 原型

選擇適合的原型層級，快速做出可解釋、可操作的核心流程。

產出：產品原型
MODULE 06

測試並決定下一步

設計成功訊號、收集使用者回饋，形成下一輪產品與市場實驗。

產出：驗證報告與迭代計畫
AI 如何融入課程

AI 是研究助手、原型協作者與營運加速器

  • 整理公開資料與競品，建立市場研究初稿
  • 協助設計訪談題目，但不假裝成真實使用者
  • 快速產出 landing page、流程稿與可測試原型
  • 將訪談逐字稿整理成模式、矛盾與待驗證假設
  • 協助建立內容、客服與營運的初版工作流

常見問題

開始前，你可能想知道

課程的正式期數、時數、費用與授課方式將在開課公告中確認。

完全不會寫程式也能參加嗎？

可以。課程重點是問題驗證與原型，不要求工程背景；會依題目選擇無程式、低程式或 AI 輔助方式。

一定要已經有創業點子嗎？

不一定。第一個單元會建立問題機會清單；有點子的人則會先檢查它是否建立在真實問題上。

課程結束會完成正式產品嗎？

目標是可測試的 MVP 原型與驗證證據，不承諾完整商業產品。這能避免在需求未確定前過度開發。

可以帶公司內部題目來嗎？

可以，但須確認資料與權限。涉及機密時應先去識別化，並避免將敏感資料輸入公開 AI 服務。
