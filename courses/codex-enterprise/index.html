04 · 課堂怎麼進行

一項任務，從定義一路做到交接。

  1. 01認識 Codex 與工作環境

    熟悉基本操作、工作資料與任務範圍；理解需要人工判斷與確認的環節。

  2. 02把模糊需求變成清楚任務

    寫出工作目標、輸入資料、限制、交付格式與完成標準，拆解多步驟工作。

  3. 03從資料到工作成果

    選擇一種部門情境，逐步整理資料、製作初稿、補齊缺漏與調整表達。

  4. 04查核來源與修正結果

    核對數字、日期、引述及推論；標示未知資訊，檢查格式與可讀性。

  5. 05建立可重複使用的流程

    將有效做法整理成任務範本；進階班練習以 Skill 保存操作步驟與驗收規則。

  6. 06成果展示與回到部門

    說明作品、人工修改與使用條件，選定下一項可應用的工作題目。

授課方式：示範 → 學員實作 → 講師回饋 → 修正 → 成果展示。工具以 Codex 為主，依企業核准的帳號與權限安排。

06 · 安排內訓前的常見問題

先確認條件，讓課堂直接進入實作。

不會寫程式，也能參加嗎？

可以。入門與部門班以研究、文件與工作流程為主，具備基本文書及瀏覽器操作能力即可；進階 Skill 練習依學員程度安排。

可以使用公司的真實資料嗎？

課前確認公司資料與工具政策。優先使用公開、模擬或去識別資料，真實資料需在企業允許的範圍內使用。

需要哪些設備與帳號？

自備電腦與網路，課前確認 Codex 帳號、可用功能、額度及 IT 權限。外部工具連接與雲端操作另行確認授權。

HR 怎麼判斷學習成果？

課前約定工作題目與完成標準，課中檢視作品、來源與修改紀錄。課後可由主管追蹤一項實際應用；回訪或講師陪跑另行約定。

可以保證節省多少時間嗎？

效果取決於資料品質、工作流程與使用熟練度。先以一項工作試行，記錄修改次數、處理時間與品質，再評估是否擴大。
