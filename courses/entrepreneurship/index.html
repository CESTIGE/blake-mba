創業實戰課程

不先寫一份看起來完整的商業計畫，而是先找到值得解決的問題、建立可被推翻的假設，完成第一輪市場驗證。

這堂課的核心任務

把「我想創業」推進到「我知道下一個要驗證什麼」

適合對象
創業準備者、接案者、顧問與新事業負責人
學習方式
問題研究＋商業假設＋訪談驗證＋行動設計
最終成果
問題定義、價值主張、驗證紀錄、最小行動計畫
這堂課適合你嗎？

如果你有創業念頭，卻還缺少驗證順序

01

想法很多，無法聚焦

每個方向都像機會，卻沒有判斷哪個問題最值得先投入。

02

先做產品，還沒問市場

投入時間與資源後，仍不確定客戶是否真的願意改變。

03

商業模式停在紙上

能說出收入來源，卻還沒有真實行為與證據支持。

04

不知道下一步做什麼

資訊蒐集很多，仍缺少本週可以完成的小型實驗。

學習成果

完成課程後，你會帶走四份創業驗證資產

01

問題與客群定義

清楚說明誰在什麼情境中，遇到什麼值得處理的問題。

02

商業假設地圖

拆出價值、通路、收入與交付中最需要先驗證的部分。

03

訪談與證據紀錄

保存真實行為、反證、替代方案與重要決策依據。

04

最小行動計畫

把創業方向轉成可執行、可衡量、可調整的市場實驗。

課程單元

從觀察問題，到完成第一輪市場驗證

每個單元都對應一份產出，讓創業進度不只停在想法與討論。

MODULE 01

建立問題機會清單

從工作、生活與產業觀察整理值得研究的問題。

產出：問題機會清單
MODULE 02

聚焦早期客群

縮小情境與對象，找到能接觸、能訪談的第一群人。

產出：客群情境卡
MODULE 03

拆解商業假設

找出價值、通路、交付與收入中的最大不確定性。

產出：商業假設地圖
MODULE 04

進行問題訪談

用非誘導式問題理解真實行為、替代方案與成本。

產出：訪談腳本與紀錄
MODULE 05

建立價值主張

把問題、承諾、差異與最小解法整理成一頁說明。

產出：價值主張一頁紙
MODULE 06

設計最小行動

選定成功訊號、測試方式與下一輪要保留或調整的內容。

產出：市場實驗計畫
FROM PRACTICE

創業方法來自實際做產品、找客戶與修正方向

課程把真實創業現場常見的模糊問題，轉成可以研究、訪談、測試與回顧的步驟；不以成功故事取代驗證。

  • 先確認問題，再討論產品與功能
  • 用真實行為與反證修正直覺
  • 控制投入，先驗證最大的不確定性
  • 保存決策與證據，形成可重複的方法
適合度指引

這堂課適合願意面對市場的人。

適合

  • 願意接觸真實客戶並調整假設
  • 希望用小型實驗降低創業風險
  • 需要一套清楚的驗證與行動順序

不適合

  • 期待課程保證募資、營收或創業成功
  • 不願接觸市場，只想完成商業計畫書
  • 已決定所有答案，不打算根據證據調整
常見問題

開始前，你可能想知道

正式日期、形式、時數與費用將在課程公告中確認。

還沒有創業題目也能參加嗎？

可以。課程會從問題機會清單開始，協助你建立可以研究的候選方向。

需要先成立公司嗎？

不需要。課程重點是問題與商業驗證，不以公司登記作為參加條件。

課程會完成正式產品嗎？

不一定。課程目標是完成驗證資產與最小行動，避免在證據不足時過度投入。
